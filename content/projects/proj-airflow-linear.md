# Airflow provider for Linear

Repository: [github.com/sgoley/unofficial-apache-airflow-providers-linear](https://github.com/sgoley/unofficial-apache-airflow-providers-linear)

An unofficial Apache Airflow provider for Linear. It is the installable piece for DAGs that need to open, update, or react to Linear issues without a one-off HTTP hook in every pipeline.
