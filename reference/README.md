# Reference

`case-study-framework.md` is the outline for the public case studies.

`reference/stacks/` holds the original employer diagrams and the private dumps used to write those studies. That folder is gitignored. This repository is the public site: GitHub Pages can serve any tracked file, and markdown under `content/` is indexed into the public assistant. Do not move these images or notes into `content/`, `assets/`, or any tracked path until a version has been rewritten for publication.
