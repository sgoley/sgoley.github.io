Linear Widgets Support

For help, contact Scottmgoley@gmail.com.

Connection help

Live use requires your own Linear personal API key with permission to read the relevant workspace. Enter it in the app connection form. To try the app without credentials, choose Explore demo in Settings.

Widgets

Create a saved view in the app, add a Linear Widgets widget to your Home Screen or Mac desktop, and select that saved view in widget settings. Refresh is periodic or on demand and is not real time.

Reporting a problem

Include your device, operating system, app version, and steps to reproduce the issue. Do not send API keys, private issue content, or confidential workspace information. Remove sensitive information from screenshots.

Removing local data

Use Disconnect in Settings to remove the saved API key, saved views, and cached issues from the device.
