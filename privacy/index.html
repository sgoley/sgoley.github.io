LLM Projects

Privacy Policy

Last updated October 20, 2026

LLM Projects is the name used for a collection of personal software projects developed and operated by Scott Goley. This policy describes Google account data handling for projects currently connected to this OAuth configuration, including Sub Notes and calendar workflows run through n8n.scottgoley.com. Each project may process different data to provide its features.

Who operates your instance

Scott Goley operates the connected personal projects and their private services. Sub Notes stores its application data in a private PocketBase database. Calendar workflows run through a private n8n instance at n8n.scottgoley.com. These services are not a public shared service for unrelated users. Scott Goley administers their servers, databases, workflows, backups, and retention.

Information the app processes

Depending on the project and feature, the connected services may process:

  • YouTube video URLs, channel or feed subscriptions, public video metadata, and transcripts selected for Sub Notes summaries.
  • Substack feed or post information selected for Sub Notes processing.
  • Generated summaries, tags, processing status, and token-usage or estimated-cost metadata.
  • Configuration settings, such as an Obsidian vault location, preferences, and workflow settings.
  • Google Calendar data made available by the scopes you authorize and processed by configured n8n calendar workflows. Depending on the workflow and granted permissions, this may include calendar and event details needed to sync calendars.

How information is used and shared

Sub Notes uses the YouTube Data API and public Substack feeds to retrieve content you select. When you request a summary, relevant content is sent to the Google Gemini API for summarization and tagging. If you configure Obsidian sync, generated notes are written to the configured vault. Calendar workflows use Google Calendar data to perform the sync actions configured in n8n. Google services process data under Google's applicable terms and policies.

Google account data is used only to provide the project feature you authorize. It is not sold or used for advertising. Data may be processed by Google APIs and services when needed for the feature you request, and is not shared with unrelated parties. The project operator can access data stored in the connected private services.

Google account data

Sub Notes uses Google authorization for YouTube API features, and n8n uses Google authorization for calendar sync. Google shows the requested permissions on its consent screen. Access is used for the feature that needs it and according to the permissions you grant. Other personal projects may request additional Google permissions in the future; their use should be described before you authorize them.

You can revoke an app's Google account access from your Google Account permissions. Revoking access prevents future authorized requests; it does not automatically remove data already stored in PocketBase, n8n workflow data, backups, or generated notes.

Storage, retention, and deletion

Sub Notes stores subscriptions, summaries, tags, settings, and processing metadata in its private PocketBase database. Calendar workflow credentials and execution data are handled by n8n according to its configuration. If Obsidian sync is enabled, generated notes are written to the configured vault. The project operator controls retention, backups, and deletion. Google API access can also be revoked in your Google Account, but that does not erase information already stored in these services.

Security

Connected services use private infrastructure administered by the project operator. The operator is responsible for protecting servers, databases, API keys, OAuth credentials, and administrator access. No method of storage or transmission is completely secure.

Children

These personal projects are not directed to children under 13.

Changes to this policy

This policy may be updated as connected projects change or add features. The latest version will be published at this address with its updated date. If a project requests new types of Google data, its intended use should be explained before you grant access.

Contact

For questions about this policy or these projects, contact Scott Goley through the Sub Notes GitHub issue tracker.
